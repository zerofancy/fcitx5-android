为什么选这组

选择默认内存策略、CPU 2 线程、6 秒新音频＋1 秒左重叠。它在已测的连续中文与绕口令中保真度最好；2＋1 秒虽然刷新更快，但边界重复更严重。没有将未经验证的「6＋1 + 低内存」组合直接用作默认。

已实现的交互与保护

  • 在现有“空格键长按行为”中增加离线语音选项，保留用户原偏好。短按仍输入空格；横滑在长按前移动光标并阻止录音。
  • 成功启动采音后提供一次开始振动，遵循现有振动偏好；抑制同次手势的通用长按及抬手振动。空格改为“松手结束”，状态占据原候选工具栏，点击 × 取消。
  • 持续使用 setComposingText 替换整段语音草稿，最终只 finishComposingText 一次；不逐段 commit，不自动发送、回车或补空格。既有可见 Fcitx preedit 先原样定稿。
  • 原始手指抬起结束；其他手指抬起不结束。系统 CANCEL、返回键、状态栏取消、键盘隐藏、主题重建、目标切换与销毁均撤销写入许可。显式取消只在范围仍可验证时清除本次草稿，其他不确定情况保留已有文字。
  • 绑定连接与单调会话代次，使用服务的选区预测；外部光标、选区或 composing 变化取消。密码、非空选区、未知光标与 TYPE_NULL 不开始；宿主拒绝 composing 时停止，避免重复提交补救。
  • 数字静音低能量门限只过滤极弱信号；拒绝模型控制标记与字面 language 输出。它不是完整 VAD，不能保证消除一般噪声、背景人声或弱信号幻觉。Android 10+ 检测系统静音，采音失败明确结束。
  • 模型固定 SHA-256 校验后解包到 noBackupFilesDir，准备前检查可用空间；不存录音、不记录识别正文、不上传音频。JNI 加载、解码、释放均串行；取消不会并发释放仍在使用的 native 实例。

安装与启用

  1. 安装 ARM64 语音版 APK。当前制品约 1019 MiB，另需约 941 MiB 私有模型副本及 Android 安装开销；普通构建不携带权重。
  2. 按系统方式启用并切换到该输入法，再打开应用 → 虚拟键盘 → 准备离线语音输入，允许麦克风权限并完成模型准备。
  3. 返回虚拟键盘设置，将“空格键长按行为”改为“离线语音输入（Qwen3-ASR）”。
  4. 在普通文本输入框长按空格，开始反馈后说话，松手定稿；状态栏 × 可取消。测试后恢复原默认输入法和长按偏好，不替用户长期切换。

模型仅在构建阶段按固定版本下载，使用时无需联网。About 开源许可与 assets/voice-notices 包含 Qwen3-ASR、sherpa-onnx、ONNX Runtime 及第三方声明。

构建与复现

ANDROID_HOME=/home/zero/Android/Sdk ./gradlew \
  :app:assembleDebug :app:testDebugUnitTest :app:assembleDebugAndroidTest \
  -PbuildABI=arm64-v8a -PbundleVoiceModel=true --offline --console=plain

首次准备制品需要网络：Gradle 的 prepareVoice 调用 tools/prepare-voice.py，复用缓存或下载固定 AAR 与 6 个模型文件，并校验 SHA-256。上例 --offline 仅约束 Gradle 依赖解析；离线重建还要求模型缓存已备妥。普通构建默认 bundleVoiceModel=false，显式语音包仅允许 ARM64。

python3 tools/voice-p0/verify_production.py \
  --serial DEVICE_SERIAL --id FRESH_ID
python3 tools/voice-p0/build_v1_report.py FRESH_ID \
  --instrumentation-log PATH_TO_DEVICE_TEST_OUTPUT

复现脚本默认触点对应 NX888J 的 1260×2800 竖屏，其他布局使用 --space-x / --space-y；需先安装生产 APK、lab APK 和测试样本，并明确启用语音长按选项。有限录音档位是测试步骤，不是产品时长限制。前置制品与样本准备见 P0 复现说明。

首版仍有的限制

  • 目标是此次验证的高内存 ARM64 设备。内存仍约 2.3–2.4 GiB，6＋1 秒窗口在较长讲话中可能需要数秒刷新或定稿；低端机未验证。
  • 重叠文本匹配没有可靠词级时间戳，重复句、专名、快语速及噪声仍可能重复、漏字或改错；过滤控制标记与静音不等于准确率达标。
  • 未完成多应用编辑器兼容矩阵、30 次会话稳定性、长时间温控和内存平台验证；不声称无限时长已测。当前实机是 4 KB 页，16 KB 环境未运行验证。设置页只准备磁盘模型，不主动预热推理。
