Gradle 钥匙圈签名

主应用与所有扩展插件共用此配置。keystore 保存在仓库外；系统钥匙圈保存 keystore 密码和私钥密码。使用 Gradle Keyring 0.2。

1. 本机配置

将 keystore 保存在仓库外，例如用户目录的 ~/.android/keystores/。Linux / macOS 建议目录权限为 700、文件权限为 600。请保留备份。

在仓库根目录的 local.properties 加入以下配置，并填写实际文件绝对路径和私钥别名。此文件已被 Git 忽略。初始化成功前保持关闭：

keyringSigning=false
keyringStoreFile=/absolute/path/to/release.jks
keyringKeyAlias=your-key-alias

2. 初始化密码

在已登录桌面、系统钥匙圈可用的本机终端运行：

# 在仓库根目录执行
./scripts/init-keyring-signing.sh

脚本先隐藏输入两个密码，私钥密码留空表示与 keystore 密码相同，再分别调用插件任务保存。密码通过短期环境变量传给 Gradle，不进入命令行参数、命令历史或项目文件。两个密码都保存成功后，将 local.properties 中的开关改成 keyringSigning=true。

Windows 或需要单独更新密码时可直接使用插件任务；插件从标准输入读取密码。脚本适用于 Bash（Linux / macOS）：

./gradlew --no-daemon --no-configuration-cache --console=plain -PkeyringSigning=false :setSecretValue --name=android_store_password
./gradlew --no-daemon --no-configuration-cache --console=plain -PkeyringSigning=false :setSecretValue --name=android_key_password

Linux 需要会话 D-Bus 和已解锁的 Secret Service / 兼容钥匙圈服务。首次访问可能出现桌面授权或解锁提示。

3. 验证并打包

# 验证 keystore 密码、私钥密码、别名及证书链；不编译 APK
./gradlew --no-configuration-cache :app:verifyReleaseSigning

# 构建主应用
./gradlew --no-configuration-cache :app:assembleRelease

# 构建所有扩展插件
./gradlew --no-configuration-cache assembleReleasePlugins

也可保持本机开关关闭，每次用 -PkeyringSigning=true 启用。该参数优先于 local.properties；文件路径与别名也可用同名 -P 参数覆盖。

行为与边界

模式行为
keyringSigning=false / 未配置保留原有 SIGN_KEY_FILE、SIGN_KEY_BASE64、SIGN_KEY_ALIAS、SIGN_KEY_PWD 及对应项目属性签名逻辑；无原配置时 Release 不签名。Debug 使用默认调试签名。
keyringSigning=true使用本机路径、别名和两个钥匙圈密码。信息缺失时直接报错，不退回未签名 Release。

钥匙圈秘密名为 android_store_password 和 android_key_password，服务名为 Gradle Project fcitx5-android。更改根项目名需要重新录入。插件读取顺序为项目属性、环境变量、系统钥匙圈；对应属性为 signStorePassword / signKeyPassword，环境变量为 SIGN_STORE_PASSWORD / SIGN_KEY_PASSWORD。

启用本机钥匙圈签名后，Gradle 配置阶段（包括 IDE 同步）会读取密码。请保持配置缓存关闭；代码会拒绝此模式下的配置缓存请求，避免把签名密码写入配置缓存。初始化和管理凭据时使用 -PkeyringSigning=false --no-configuration-cache，避免密码尚未存在时阻塞任务。

查看配置名可运行 ./gradlew -PkeyringSigning=false --no-configuration-cache :listSecretConfigs。不要使用 listSecretValues，它会输出密码。keystore 与钥匙圈密码均需自行备份；只有其中一个无法完成签名。
