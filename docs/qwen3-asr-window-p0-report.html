1. 结论

尚未找到同时满足延迟、1.5 GiB 增量内存预算及拼接质量的配置。默认 CPU 配置可以显著缩短长录音的刷新和结束等待，测试进程峰值 PSS 仍约 2.1–2.3 GiB，扣除加载前基线后仍超预算；低内存配置约 1.3–1.4 GiB，但速度、积压和短段识别质量仍有问题。
  • 总时长与单次解码长度已经分离；长录音不再整段送入 512-token 导出模型，因此不应把原模型上下文上限换算成产品录音上限。
  • 3 分钟是实验观测时长，不是产品限制，也不是“任意时长已通过”的承诺。持续输出文字仍会自然增长；有界的是音频缓冲与单次模型输入。
  • 本轮不接入生产空格长按。先解决模型常驻内存与稳定拼接，再按原交互规范推进。

2. 实验条件与实现

同一 NX888J / SM8850 / Android 16 / arm64 / 4 KB 真机；同一 sherpa-onnx v2.0.1 AAR、同一固定 Qwen3-ASR-0.6B INT8 权重和 tokenizer，未更换模型。CPU 默认 2 线程，低内存组合额外试 4 线程。

  1. 音频生产线程独立采样或按真实时间重放，样本位置使用 Long；解码保持一个 worker。每段处理 C 秒新音频，附带 O 秒左侧音频重叠，单次输入不超过 C+O 秒。
  2. 环形缓冲容量固定为 3C+O+1 秒。2+1 配置容量 8 秒 / 128,000 个 Float32 样本，约 0.49 MiB；单次 3 秒快照约 0.18 MiB。实验音频 fixture 是固定源，不随总录音长度复制。
  3. 逐段按顺序处理，既不跳过旧段，也不提前 commit。已识别段和当前假设拼成同一份全文，通过系统 InputConnection 替换同一个宿主 composing。
  4. 文字拼接使用归一化 token 的最长精确后缀 / 前缀匹配，或有限编辑距离匹配；重叠文字可回改。无法匹配时保留内容并记录 unmatched；多个匹配记录 ambiguous，不能假装没有风险。
  5. plain 调度保留原增量更新节奏；deadline 调度估算下一次 partial 成本，若可能跨过分段边界则等待段结束，减少冗余解码。这个策略也可能造成更长刷新间隔，已单独列出。
  6. 如果 worker 落后到环形缓冲覆盖了未处理音频，明确报 overrun 并失败，不静默丢音。没有按总录音时长自动停止的产品规则；实验 seconds 只模拟本次有限时间后的抬手。

分桶只包含录音开始到最终输出结束的内存采样，排除了模型释放阶段；全流程峰值还包含加载期。默认配置的主要占用来自模型 / 运行时，不是录音缓冲，因此限制单次解码窗口不会自动把模型峰值降至 1.5 GiB。

首尾完整 30 秒桶的 PSS 中位数相差约 +115 MiB，仍存在缓慢增长，尚未证明长期平台期。有界音频缓存不等于全部进程内存恒定；原始数据同时记录 native 已分配字节数，尚未进一步归因到 arena、其他分配器或日志 / 编辑器开销，不能仅凭增长就断言泄漏。

额外关闭 CPU arena / memory pattern 的 60 秒对照：峰值 PSS 2094 MiB，相对加载前增量 2031 MiB，结束等待 2.06 秒。占用有所降低，但仍高于预算；只测了 60 秒，不能据此认定长期增长已经解决。

成功执行的窗口实验中，音频顺序覆盖异常：无；导出上下文 / 输出截断警告：无。coverage 验证的是已接受采样被连续处理，并不等于识别正文没有漏字。

第二条独立中文的 2+1 窗口出现大量重复，不能把第一条样本较好的延迟推广成可用结论。参考转写来自固定模型包附带的 transcript.txt；标点去除，中文按字符、英文按单词计算编辑距离，列出替换、删除和插入数。参考文本尚未独立人工审听核对，结果用于诊断回归，不应当作公开标准测试集或最终绝对准确率。精确计数、正文哈希与 seam 类型可在指标 JSON 复核。

模型在不同音频边界可能改写同一个词；重复词组也可能让后缀 / 前缀存在多个合理对齐。纯文字重叠启发式缺少可靠时间戳，存在重复、误删和错误冻结前段文字的风险。更大重叠不保证更准确，也会增加计算。不能只用刷新频率判断方案可用。

7. 可见 IME 的真实麦克风验证

WindowMicrophone 使用真实 AudioRecord 将 PCM 写入同一固定 ring；手机扬声器播放已知语音、内置麦克风回采，媒体音量临时调至 8/15 后恢复。该项最大停止采集偏差为 36.1 ms。不是人工现场口述，也不保存原始麦克风录音。

采音与解码分线程；关闭采集后，只处理 ring 内剩余段。初始设备采音延迟和末尾硬件缓冲未做逐词对齐，因此不能把 accepted sample 覆盖检查当成物理尾字已经验收。
